Notable Engineering Decisions
🧩 Fail-soft everywhere

Every intelligence module (retention, competitor, verifier, A/B) is wrapped in try/except that never blocks the main pipeline. A YouTube Analytics scope error doesn't stop tonight's upload batch.

🔑 No secrets in git

config.json and tokens/ are .gitignored. TikTok access tokens stored encrypted per-account. OAuth refresh handled transparently by google-auth with Credentials.refresh(Request()).

⚖️ ToS boundaries hard-coded

TikTok is never auto-published — per-post human consent enforced at the autoschedule layer. YouTube publishAt scheduling used instead of live uploads to avoid rate limits.

📦 spandrel over basicsr

basicsr fails on Python 3.13 (KeyError: '__version__'). spandrel is a modern ESRGAN runner with no basicsr dep. Tiled processing manages VRAM — configurable tile_size=512.

🗂️ Flat file library

No database. Each video is a .mp4 + .json sidecar pair. list_videos() globs review/. Simple, zero-dependency, git-diffs cleanly, survives power cuts. Works fine at this scale (hundreds of videos).

📡 SSE for job streaming

make_short runs in a background thread, stdout captured and streamed to the dashboard via Server-Sent Events. No WebSocket dependency. Works in all browsers, reconnects automatically.
